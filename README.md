# WEB103 Project 3 - *Chicago Plaza*

Submitted by: **Erika Villalpando**

About this web app: **Chicago Plaza is a virtual community space where users can explore popular Chicago locations and discover upcoming events. Users can select a location from the interactive Chicago map to view event details, including dates, descriptions, and costs of each event.**
